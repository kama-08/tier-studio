# Tier Studio 0.1.0

The first public Windows release of Tier Studio, an offline tier list editor.

- Create projects with image and text items, drag items between tiers, and undo changes.
- Customize item shapes, sizes, spacing, tier labels, colors, borders, and shadows.
- Export PNG images with a preview, adjustable width/resolution, and your current theme.
- Save and import portable `.tier` files with embedded images and styles.
- Use light/dark appearance, a hideable sidebar, a system tray, and a single desktop instance.

## Install

Download **Tier-Studio-windows-x64-setup.exe** below for Windows 10/11 on an Intel or AMD 64-bit PC.
Run it and choose an installation folder. It installs for the current Windows account.
The installer sets up the Microsoft WebView2 runtime if needed; that step requires a connection.

This initial installer is unsigned, so Windows may display an unknown-publisher warning.
The `SHA256SUMS.txt` asset records its SHA-256 checksum. On PowerShell:

```powershell
Get-FileHash .\Tier-Studio-windows-x64-setup.exe -Algorithm SHA256
```

## Projects and known limits

Browser and desktop libraries are separate. Choose **Save project** in the browser,
then import the resulting `.tier` file into the desktop app. Export important projects as backups.
Closing the desktop window hides it in the system tray; choose **Quit** from the tray to exit.

Automatic updates, accounts, cloud sharing, and macOS/Linux installers are not included in this release.
