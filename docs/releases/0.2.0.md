# Tier Studio 0.2.0

- The redesigned workspace puts saved projects first and offers the sample board when the library is empty.
- The editor has a more compact heading and toolbar, with **Add a tier** alongside the board tools. The sidebar animates when toggled and follows your reduced motion preference.
- The PNG export dialog previews your chosen board width and resolution and lets you include or omit the project title. Exported images omit project descriptions. Existing descriptions are preserved in `.tier` project files.

## Install or update on Windows

Download **Tier-Studio-windows-x64-setup.exe** and run it to install or update Tier Studio on a 64-bit Windows 10 or 11 PC. The installer runs for the current Windows account and can set up Microsoft WebView2 if needed.

The installer is unsigned, so Windows may show a publisher warning. The `SHA256SUMS.txt` asset contains the installer’s SHA-256 checksum.
